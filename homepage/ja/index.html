04SCOPE

CAPABILITIES, NOT PROMISES

できることと、
まだしないこと。

実装済み、接続コードのみ、未検証を分けて表示します。未確認の数字・ロゴ・レビューは作りません。

工程状態補足
録画・ローカル動画合成実装あり操作録画、字幕、横長・縦長。
シーン構成・制作パッケージベータSeedance用指示、エージェント用タスク、AE用JSX。
完成動画の取り込み→投稿準備実装ありH.264/AAC MP4、最大200 MB・5分。版管理し、新しい動画は個別承認。
Seedance 2.5・コーディングエージェント実行明示実行を実装fal専用Queue連携と隔離Codex / Claude Code runner。実課金APIはリポジトリテストでは実行していません。
After Effectsガード付き実行WindowsのJSX実行と両OSのaerender経路。AE実機・映像品質は未検証。
Postizでの投稿・予約接続コードあり実SNSアカウントでの公開は未検証。公開には別途承認が必要。

キャンペーンを作り、制作ボードで整え、完成動画を戻して確認し、投稿準備へ進めます。

セットアップを見る ↗使って分かったことを送る
$ git clone https://github.com/FORIFOR/Launchloom
$ cd Launchloom
$ python -m pip install -e .
$ python -m playwright install chromium
$ python -m launchloom serve
公開サイトと制作アプリは別です。

外部ツールへ素材を渡す前に、機密情報・権利・料金を確認してください。制作ボードを開いただけでは課金やSNS公開は行いません。
