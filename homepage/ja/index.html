LOCAL-FIRST LAUNCH STUDIO

操作録画を、
紹介動画と
投稿案に。

ひとつの企画から、横動画、縦動画、紹介ページへ。素材を作るところから、届ける前の確認まで、手元のワークスペースにまとめます。

ローカル・1人用アルファ / Apache-2.0
外部AI・Adobe・投稿サービスの利用条件と料金は別です。

ONE CAMPAIGN, LESS HANDOFF

作るものを、
あちこちに散らさない。

録画、構成、出力、投稿下書き。同じキャンペーンの中で、次に確認するものが分かります。

01 / RECORD

動いている製品を見せる。

操作録画を取り込むか、許可したテスト環境を収録。紹介してよい機能と、見せてはいけない情報を分けます。

02 / EDIT

構成を読んで、直す。

見出しや字幕を確認し、素材を再利用して調整。横長・縦長それぞれの画面に合わせて書き出します。

03 / REVIEW

届ける前に、確認する。

動画、紹介ページ、媒体別の投稿文をまとめて確認。公開許可と個々の投稿承認は、制作とは別の工程です。

NEW / PRODUCTION HANDOFF BETA

生成映像も、AEの演出も。
まず、一本の構成にまとめる。

シーンごとに制作手段、秒数、見出し、演出指示を編集。Seedance用の指示、Codex／Claude Code用タスク、After Effectsの基本タイムライン用JSXを、ZIPにまとめて渡せます。

工程を説明する表示です。生成済み動画や、実行中のジョブではありません。

この版でできること

シーンの編集・並べ替え・保存、指示とJSXの書き出し。基本タイムラインを作るための、読み直せる制作パッケージを残します。

別の作業が必要なこと

Seedanceでの生成、エージェント実行、AEの実機操作・書き出し、完成動画の取り込み。これらの自動実行はまだ含みません。

外部ツールに素材を渡す前に、機密情報・権利・料金を確認してください。制作ボードだけでは有料処理は実行されません。
