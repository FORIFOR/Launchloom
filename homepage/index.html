ACTUAL WORKFLOW / NO EXTERNAL POST

Make it. Review it.
Prepare it for publication.

A real local-app recording: edit the plan, import a film, select a reviewed version, and preview a publication without sending it.

01

Choose a tool for each scene.

Recording, Seedance, or AE. Save durations and directions. Seedance requests need data and cost confirmation; retries reconcile the stored job.

02

Keep the exact version you reviewed.

Import without changing your original. Selecting a different film invalidates old unsent approvals and holds the campaign for a fresh release decision.

03

Make publishing a separate decision.

Review the film, copy, account, and time. Postiz acceptance and confirmed social publication are tracked separately.

Inspect a production handoff sample ↓

The sample contains a plan, creative instructions, and AE JSX. No completed Adobe project or paid-generated media is bundled.

WHAT IS READY

Clear capabilities. Clear boundaries.

Implemented does not mean tested against every external service. Here is what this build actually includes.

CapabilityThis buildRequirements and verification
Recording → film, page and draftsLocal productionExisting workflow; external AI is optional.
Finished film → review → publication draftImplemented & testedMP4/MOV/WebM. Actual browser flow through import, selection and a no-send preview.
Seedance 2.5Scene generation API adapterRequires a fal key and paid-generation permission. Paid output quality is not live-verified.

After EffectsJSX + local CLIWindows JSX invocation and aerender command. On macOS, run JSX manually in AE. Requires licensed Adobe software and real-machine verification.
Postiz publishing & schedulingApproval-gated API adapterSubmission and duplicate prevention tested with a fake publisher. Real social-account publication is not verified.
