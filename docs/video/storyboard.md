# Launchloom 実動作動画 — 絵コンテ（撮影前に確定）

作成 2026-09-22。撮影対象は **Obsidian テーマ適用後の現行アプリ**（main 60241eb）。
旧 `demo.gif` / `homepage/intro.mp4` は改修前UIなので流用しない。

## 何を見せるか（1文）

**一人でプロダクトを作った開発者**が、**紹介動画・LP・SNS原稿を用意できずローンチで止まる**問題を、
**実際の画面収録から同じ企画で全部を生成するローカルツール**で解決する。
納得の materialは **「字幕を1つ直す → 保存 → 実際にその文字が入った動画が書き出される」** という一連。

選んだ代表体験：**編集が実出力に反映されることを、同一画面内で見せる。**
機能の羅列ではなく、「直した文字が、できあがった動画に入っている」一点に絞る。

## X 用 9:16（目標 18秒）

同じ収録から別編集。中央切り抜きではなく、**UIを再配置**する:
- 上部：プレイヤー（16:9のまま、上寄せ）
- 中央：操作中のUI領域だけを拡大して配置
- 下部：大きめの字幕（縦画面・無音前提）

カット：0–3秒 完成画面 / 3–10秒 字幕編集 / 10–15秒 反映された動画 / 15–18秒 入口。

## 撮らないもの

- ロゴだけの長い導入
- 機能の羅列
- 意味のない発光・球体・グラデーション
- 実際には通っていない経路（外部投稿・有料生成）

## 正直さの制約（編集で偽らない）

- **待ち時間を縮めた箇所は画面上に明示する。** レンダリングは実測で約30秒かかる。
  等速では尺に収まらないので早送りし、`実時間 約30秒を短縮` と字幕を出す。
- 成功率・処理速度・連携状況を編集で作らない。
- サンプルは同梱の Orbit（このリポジトリのテスト用アプリ）であることを明示する。
- 音声は入れない（サンプルに音声トラックが無いため）。自動再生時も無音。
