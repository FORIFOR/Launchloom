架空のダッシュボードは置きません。ここにあるのは、Launchloomから実際に作ったページと、公開前の確認画面です。

見せるものと、
送るものを分ける。

紹介ページや動画を作る工程と、公開を許可する工程を分離。仕上げた動画は版として取り込み、選んだ版を投稿準備へ渡します。

ONE CAMPAIGN

作る。仕上げる。
確認して、届ける。

機能一覧ではなく、一本の成果物が公開できる状態になるまでの順番です。

01

Record

本物の操作画面を収録。紹介してよい機能と機密情報を分けます。

02

Shape

シーン、字幕、画角を整え、横長・縦長を同じ企画から作ります。

03

Finish

外部で仕上げたH.264/AAC MP4を変更不可の版として取り込み、実際に再生して確認します。

04

Publish

選んだ完成動画と投稿文を確認し、公開許可と個々の投稿承認を別々に扱います。

CAPABILITIES, NOT PROMISES

できることと、
まだしないこと。

実装済み、接続コードのみ、未実装を分けて表示します。未検証の数字・ロゴ・レビューは作りません。

工程状態補足
録画・ローカル動画合成実装あり操作録画、字幕、横長・縦長。
シーン構成・制作パッケージベータSeedance用指示、エージェント用タスク、AE用JSX。
完成動画の取り込み→投稿準備実装ありH.264/AAC MP4、最大200 MB・5分。版管理し、新しい動画は個別承認。
Seedance専用API・エージェント自動実行未実装外部環境へ手動で渡します。
After EffectsJSX書き出しAE実機の操作・映像品質は未検証。
Postizでの投稿・予約接続コードあり実SNSアカウントでの公開は未検証。公開には別途承認が必要。

YOUR MACHINE. YOUR WORKSPACE.

まずは、手元の素材で。

通常のスタジオでキャンペーンを作り、制作ボードで構成し、完成動画を取り込んで確認・投稿準備へ進みます。

セットアップを見る ↗使った結果を伝える
git clone https://github.com/FORIFOR/Launchloom
cd Launchloom
python -m pip install -e .
python -m playwright install chromium
python -m launchloom serve
公開サイトと制作アプリは別です。

外部ツールへ素材を渡す前に、機密情報・権利・料金を確認してください。制作ボードだけでは有料処理やSNS公開は実行されません。
